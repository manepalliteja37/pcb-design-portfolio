
# Automatic Irrigation Control PCB

This project is a soil moisture monitoring and irrigation automation system.

## Features
- 4 moisture thresholds (10%, 30%, 60%, 90%)
- LM339 comparator based control
- Automatic motor activation

## Tools Used
- KiCad
- Analog circuit design
- PCB routing

## Hardware Components
- LM339 comparator
- Soil moisture sensor
- Relay module
- DC motor

## Files Included
- KiCad schematic
- PCB layout
- Gerber files
- BOM
